## 🌸 `projects i've loved building` 🌸

</div>

### 🎀 Inventory Management System

**Confidential · Ministry of Defense**

A secure inventory management solution developed with a focus on reliable workflows, scalability and stakeholder validation.

**What I worked on**

* Designed and implemented front-end workflows for secure inventory handling.
* Developed a preliminary database schema to support structured inventory management.
* Collaborated with a **12-member cross-functional team** to ensure scalability and reliability.
* Worked with stakeholders to validate requirements and workflows.

**Tech**

`HTML` `CSS` `Node.js` `MySQL`

---

### 🍓 AI Diet Tracker

**Streamlit Web Application**

A nutrition-focused application designed to make food tracking simpler through natural language input and barcode-based food recognition.

**What I built**

* Integrated **Nutritionix API** for parsing meal descriptions.
* Integrated **OpenFoodFacts API** for retrieving nutrition information from food barcodes.
* Built an interactive web application for meal logging.
* Enabled users to track **calories and macronutrients**.
* Supported both natural-language meal input and barcode scanning.

**Tech**

`Python` `Streamlit` `Nutritionix API` `OpenFoodFacts API`

---

### 🦋 AI-Based Hand Gesture Presentation Controller

A computer vision application that transforms **real-time hand gestures into presentation controls**.

**What I built**

* Used MediaPipe hand landmarks for real-time gesture recognition.
* Implemented gesture-based **slide navigation**.
* Added a **virtual laser pointer** for presentations.
* Implemented **annotation drawing** directly through gestures.
* Added **undo operations** for annotations.
* Applied cursor smoothing to improve interaction quality.
* Implemented gesture cooldown mechanisms to prevent accidental commands.
* Structured the application using a modular, object-oriented design.

**Tech**

`Python` `OpenCV` `MediaPipe`
